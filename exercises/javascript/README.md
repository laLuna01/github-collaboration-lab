# Exercícios em JavaScript

As soluções poderão ser adicionadas futuramente através de Issues e Pull Requests, permitindo comparar diferentes abordagens e linguagens de programação.

## Oportunidades de contribuição

- implementar em JavaScript exercícios existentes em Python;
- propor novos exercícios;
- melhorar soluções existentes;
- adicionar documentação e exemplos.
