# Exercícios em Java

Esta pasta é destinada a implementações em Java dos exercícios de lógica do projeto.

As soluções poderão ser adicionadas futuramente através de Issues e Pull Requests, ampliando o projeto e permitindo a prática do fluxo de contribuição.

## Oportunidades de contribuição

- implementar em Java exercícios existentes em Python;
- propor novos exercícios;
- melhorar soluções existentes;
- adicionar documentação e exemplos.
