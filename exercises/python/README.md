# Exercícios em Python

Esta pasta reúne exercícios de lógica de programação implementados em Python.

Os exercícios serão adicionados gradualmente através do fluxo de colaboração utilizado neste repositório:

1. criação de uma Issue;
2. criação de uma branch;
3. implementação da solução;
4. abertura de um Pull Request;
5. revisão;
6. merge.

## Exercícios planejados

- FizzBuzz
- Verificador de palíndromo
- Sequência de Fibonacci
- Outros exercícios sugeridos através de Issues

## Contribuindo

Melhorias nas soluções existentes, novos testes, documentação e novos exercícios podem ser sugeridos através das Issues do repositório.
